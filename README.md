# 股癌研究筆記（公開摘要）

手機版：https://ckscks038038.github.io/gooaye-research/

這是非官方、AI助理協助整理的研究摘要。完整讀稿14集，10張候選思維卡，8集另有部分價格與官方消息核驗；不是已驗證投資策略。

此公開repository僅包含靜態網站與公開摘要／進度索引，不包含完整逐字稿、私人研究資料、帳戶憑證或對話紀錄。

## 部署

GitHub Pages：Deploy from a branch → main → / (root)。無第三方網站依賴、追蹤程式或付費服務。

`index.html`／`styles.css` 為靜態內容；`corpus.json` 僅匯出已核對的摘要與進度，`corpus.js` 提供手機篩選，不呼叫模型或第三方追蹤服務。變更推送至main後由Pages更新。

進度為人工核對的快照，不會自動把下載計為閱讀；尚無背景自動摘要任務。更新摘要時也須更新卡片、案例與文字敘述，避免不同區塊的狀態不同步。
