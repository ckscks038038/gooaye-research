# 股癌研究筆記（公開摘要）

手機版：https://ckscks038038.github.io/gooaye-research/

這是非官方、AI助理協助整理的學習筆記。學習版0.6以同一區呈現90張白話知識卡：使用情境、關鍵問題、兩步檢查與反例限制；來源另行展開。保留原10張內容，加入80張不同情境，取代10張重疊的歸納卡，不把兩套卡直接相加。這是主助理的教學改寫，沒有新增雙模型覆核或績效驗證。

全量範圍為固定索引693集；原稿已在私人研究環境備妥。最新筆記數、待處理數與工作流快照見網站／corpus.json。可依集號、日期、年份、主助理／子agent方法及核驗狀態篩選；未通過的草稿不提供推測性摘要。

此公開repository僅包含靜態網站與公開摘要／進度索引，不包含完整逐字稿、私人研究資料、帳戶憑證或對話紀錄。

## 部署

GitHub Pages：Deploy from a branch → main → / (root)。無第三方網站依賴、追蹤程式或付費服務。

`index.html`包含全部90張卡，停用JavaScript仍可展開閱讀。`corpus.js`增強搜尋、分類與分頁，每次顯示12張；研究JSON載入失敗不影響知識卡。研究紀錄移到卡片後方並預設收合。`corpus.json`保留逐集筆記及原歸納，並不是教學改寫的正文。

研究範圍693集：14集主助理筆記、679集雙子agent筆記；只有原先8集另有部分外部核驗。逐字定位與模型覆核不等於核對原音、行情或真實交易。研究狀態是最近一次發布快照，不保證此刻有程序運行。

模型子程序無工具或網站寫入權限，只有主程序能將允許的六個公開檔案提交並部署。完整原稿與模型日誌不公開。
